## 🛠️ 如何在 AI Agent 中使用本 Skill

本技能符合 Antigravity 及现代 Agentic 系统的通用标准规范：

### 1. 本地/全局安装（Antigravity）
将 `SKILL.md` 放置于您的全局技能目录或任意工程工作区中：
```bash
# 全局安装
mkdir -p ~/.gemini/config/skills/zhang-shuangli-critical-theory
cp SKILL.md ~/.gemini/config/skills/zhang-shuangli-critical-theory/SKILL.md

# 或项目级安装
mkdir -p ./skills/zhang-shuangli-critical-theory
cp SKILL.md ./skills/zhang-shuangli-critical-theory/SKILL.md
```

### 2. 核心分析能力
激活本技能后，AI 将具备以下六大专业分析透镜：
1. **卢卡奇物化批判透镜**（剖析商品形式普适化、事实化、量化计算与沉思看客心态）；
2. **马克思《雾月十八日》阶级解剖透镜**（剖析资产阶级为了私有制利益自愿走向“政治反动”的内在悖论）；
3. **法兰克福学派工具理性与文化工业透镜**（揭露启蒙倒退为神话、奥德修斯感性自残与文化工业伪个性化）；
4. **哈贝马斯生活世界殖民透镜**（诊断金钱与权力系统对交往生活世界的侵蚀与公共领域再封建化）；
5. **葛兰西文化领导权与阵地战透镜**（拆解常识霸权建构、市民社会堑壕战与有机知识分子）；
6. **告别单子式自我与反异化透镜**（打破新自由主义“单子化内卷”神话，重建社会性想象与互相承认）。
